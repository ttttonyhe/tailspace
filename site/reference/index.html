Tailspace / Reference

CLI, options, and reference

Tailspace is one bash file installed into ~/.tailspace with tailspace and tailscale linked into ~/.local/bin. Every command, flag, environment variable, file path, and Tailscale tweak is listed below, mirroring ADVANCED.md.

Commands

CLI subcommands

CommandWhat it does
tailspace install [options]Install Tailspace and join this server to your tailnet. Safe to re-run; preserves saved settings.
tailspace statusShow whether Tailspace is running, which path it uses, any waiting update, and recent events.
tailspace startStart the supervisor and tailscaled.
tailspace stopStop Tailscale and the supervisor, and keep them stopped across reboots.
tailspace restartRestart Tailspace. Finishes even if run over Tailscale SSH while the connection drops.
tailspace set [options]Change saved settings without reinstalling, for example tailspace set --no-ssh.
tailspace update [VERSION]Update Tailscale now. Passing a version pins it and turns daily updates off.
tailspace logs [-f]Show or follow tailscaled.log, like tail -f.
tailspace self-updateDownload and install the latest Tailspace from the repository's main branch.
tailspace uninstallLog this server out of your tailnet, stop Tailspace, and remove its files, cron job, and shell check.
Options

Install and set flags

OptionDefaultMeaning
--authkey KEYAuth key, or file:PATH. Install only. Prefer TS_AUTHKEY to keep secrets off /proc/*/cmdline.
--tags TAGSServer tags such as tag:server. Install only. Required with an OAuth client secret.
--version VERSIONlatestInstall a pinned Tailscale version and turn daily updates off. Install only.
--hostname NAMEhost nameThe server's name in your tailnet.
--proxy URL | nonehttps_proxyHTTP proxy URL for the proxy path, or none. Only http:// works.
--udp-port PORT0UDP port for direct peer links, from 1024 to 65535. Pick one if opening a firewall port.
--[no-]autostartonManage the shell check and user cron job that bring Tailspace back after reboots.
--[no-]auto-updateonDaily Tailscale updates with up to 3-day session wait and rollback.
--[no-]sshonTailscale SSH on port 22, and OpenSSH on port 2222 when present. Off sends port 22 to OpenSSH.
--[no-]log-uploadonSend Tailscale's diagnostic logs to Tailscale. Required by tailnets with network flow logs.

Environment variables

  • TS_AUTHKEYSame as --authkey, while keeping the key out of the process list. Use TS_AUTHKEY=file:/path/to/key on a mode 0600 file to keep it out of shell history too.
  • TAILSPACE_PREFIXInstall location instead of ~/.tailspace, useful when $HOME is mounted noexec or blocks file locks. Later commands find the new path on their own.
Files

Prefix layout and shared home directories

~/.tailspace/
  tailspace           Tailspace itself; the shell check and cron job run this copy
  bin/                the tailscale and tailscaled binaries
  bin.prev/           the previous Tailscale version, for rolling back
  config              your saved settings
  bad-version         a version that failed health checks after an update
  state/HOSTNAME/     everything that belongs to one server
    tailscaled.state  the server's identity in your tailnet
    tailscaled.log    the log, started over after 10 MB
~/.local/bin/         the tailspace and tailscale commands

Servers that share an NFS home directory share one ~/.tailspace while keeping separate per-host state under state/HOSTNAME/. See the HPC and Slurm guide.

Tuning

What Tailspace changes in Tailscale

ChangeWhy
GOMAXPROCS=8 when > 8 coresCut Tailscale from 57 threads to 14 and probe CPU time from 57 ms to 15 ms on a 124-core Kubernetes pod.
TS_PORTLIST=falseStops Tailscale from scanning open local ports every second for a list only the admin console shows.
TCP keepalives 60 s idle, every 15 sCloses dead peer connections in minutes instead of two hours.
UDP GSO off in containersAvoids severe throughput drops on container virtual networks; see tailscale#20858.
GODEBUG=tlsmlkem=0Prevents middleboxes from dropping ML-KEM TLS handshakes; see tailscale#20777.

Use examples/policy.hujson to define tag:server, permit autogroup:nonroot Tailscale SSH, and enable cache-network-maps on Tailscale 1.104 or newer. For error messages and stop reasons, see Troubleshooting.

FAQ

Frequently asked questions

How do I install Tailspace without putting an auth key in shell history or /proc?

Save the key to a mode 0600 file and pass TS_AUTHKEY=file:/path/to/key to the installer. Tailspace passes it to tailscale up through a pipe so it never appears in /proc/*/cmdline.

How do I pin a specific Tailscale version and turn off daily updates?

Run tailspace update 1.104.6 on an installed server, or pass --version 1.104.6 at install time. Both install that release and turn daily updates off.

How do I uninstall Tailspace cleanly?

Run tailspace uninstall. It logs the server out of your tailnet, stops the supervisor and tailscaled, and removes files, shell check lines, and user crontab entries while keeping shared binaries if another server uses the same prefix.
