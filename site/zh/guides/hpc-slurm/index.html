Tailspace / 超算与 Slurm

高校超算与 Slurm 集群免 root 安装 Tailscale

高校超算和实验室集群通常不提供 sudo、/dev/net/tun 或 systemd --user 常驻权限，还常见 CentOS 7、RHEL 与 NFS 共享家目录。Tailspace 在你的普通账号下以 userspace 模式安装并监管 tailscaled，崩溃和服务器重启都能恢复，让你免 VPN 连上 SSH、VS Code Remote-SSH 和 Jupyter。

安装前请先查看集群管理规定。 Tailspace 会在后台维持 Tailscale 进程，Tailscale SSH 也会绕过集群自己的两步验证。部分高校超算禁止登录节点常驻进程或外部隧道，请先确认规定。

安装

登录节点与 Slurm 临时计算节点

交互式安装运行默认命令：

curl -fsSL https://raw.githubusercontent.com/ttttonyhe/tailspace/main/tailspace | bash

如果是脚本部署或临时 Slurm 计算节点，把带 tag:server 标签的可重复 auth key 存入 0600 权限文件，通过 TS_AUTHKEY 传入，避免同机其他用户在 /proc/*/cmdline 看到密钥。希望作业结束后节点下线的话，创建 key 时再勾选 ephemeral：

chmod 600 ~/.ts-key
curl -fsSL https://raw.githubusercontent.com/ttttonyhe/tailspace/main/tailspace | \
  TS_AUTHKEY=file:$HOME/.ts-key bash -s -- install --hostname hpc-login-01

带标签的设备默认关闭密钥过期。把 examples/policy.hujson 放进你的访问控制策略，笔记本可以 SSH 到超算节点，同时禁止超算节点主动连向你的个人设备。编辑器与端口用法见 VS Code 与 Jupyter 指南。

共享 NFS

多节点共用同一个家目录

大多数超算在所有登录节点和计算节点间挂载同一个 NFS $HOME。多台节点直接跑单状态目录的 tailscaled 脚本会互相覆盖状态文件。

Tailspace 把每台节点的状态、锁和日志按主机名存放在 ~/.tailspace/state/HOSTNAME/ 下，同时共用 bin/、config 和 shell 检查：

~/.tailspace/
  bin/                  共享的 tailscale 和 tailscaled 程序
  config                共享配置
  state/login-01/       login-01 独立的状态、锁与日志
  state/login-02/       login-02 独立的状态、锁与日志

在每台需要加入 tailnet 的节点上各运行一次 tailspace install。卸载某一台节点时，tailspace uninstall 只清理该节点的状态目录，保留其他节点所需的共享文件。

本地盘与 CentOS 7

noexec 家目录与老内核兼容

如果家目录挂载为 noexec、文件锁失败或 Unix socket 路径过长，用 TAILSPACE_PREFIX 装到本地盘或 scratch 目录：

curl -fsSL https://raw.githubusercontent.com/ttttonyhe/tailspace/main/tailspace | \
  TAILSPACE_PREFIX=/scratch/$USER/tailspace bash
  • CentOS 7 与 RHEL支持 Linux 3.2+、bash 4.2+ 与 util-linux 2.23+，CI 在每次提交时都用源码编译的 bash 4.2 跑完整测试。
  • 多核登录节点可用核心超过 8 个时设 GOMAXPROCS=8，在 124 核 Pod 上把线程从 57 降到 14，每次状态检查的 CPU 时间从 57 毫秒降到 15 毫秒，同时设 TS_PORTLIST=false。
  • 共享主机隔离~/.tailspace 权限为 700，进程识别只读 /proc 中你自己的描述符，且关闭无密码的 SOCKS5 与 HTTP 代理。
常见问题

常见问题

超算多台节点共用同一个 NFS 家目录会冲突吗？

不会。每台节点的状态、文件锁和日志都保存在 ~/.tailspace/state/HOSTNAME/ 下，共用同一份程序，各自以独立设备加入你的 tailnet。

如果超算家目录挂载了 noexec 或不支持 flock 怎么办？

安装时传入 TAILSPACE_PREFIX=/scratch/$USER/tailspace，把 Tailspace 装到本地 scratch 盘，之后的 tailspace 命令会自己找到这个目录。

CentOS 7 这类老系统超算能运行吗？

可以。Tailspace 支持 Linux 3.2 及以上内核、bash 4.2 与 util-linux 2.23，CI 每次提交都会在源码编译的 bash 4.2 上跑完整测试。
