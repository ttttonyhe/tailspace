故障排查与常见报错

先运行 tailspace status，详细信息看 tailspace logs -f。下面列出免 root 运行 Tailscale 最常见的报错和停止状态。

常见报错

报错与处理方法

  • failed to open /dev/net/tun常规 Tailscale 安装需要 root 和 CAP_NET_ADMIN 打开内核 TUN 网卡。改用 Tailspace 即可，它始终以 tailscaled --tun=userspace-networking 运行，不访问 /dev/net/tun。
  • System has not been booted with systemd在容器或老系统运行 systemctl --user 时出现。Tailspace 不依赖 systemd，监管进程是普通用户进程，通过 cron 和 shell 检查恢复。
  • 连不上 controlplane.tailscale.com服务器需要 HTTP 代理。安装前执行 export https_proxy=http://HOST:PORT，或运行 tailspace set --proxy http://HOST:PORT。详见代理切换指南。
  • Tailscale SSH 拒绝连接确认访问控制策略里有允许你的 ssh 规则且包含 autogroup:nonroot，参考 examples/policy.hujson，并用安装 Tailspace 的账号连接。
  • 服务器重启后没有运行这台服务器没有 cron 且重启后还没人登录过。用安装 Tailspace 之前的方式或 kubectl exec 登录一次，shell 检查就会拉起它。
  • tailscaled 无法运行或 noexec家目录禁止执行程序、文件锁失败或 socket 路径太长。用 TAILSPACE_PREFIX=/scratch/$USER/tailspace 装到本地短路径。
  • 传输慢或打字延迟运行 tailspace status，若活动设备旁显示 relay，说明流量走了较远的 DERP 中继，可按代理与中继指南部署自建 DERP 或 Peer Relay。
停止状态

Tailspace 何时会放弃

遇到需要人处理的问题时，Tailspace 会停下并把原因写进 tailspace status：

status 显示发生了什么怎么办
stopped with tailspace stop你停止了 Tailspace运行 tailspace start
this server must log in again密钥过期，或有人把它从你的 tailnet 删除再运行一次 tailspace install
adding this server to your tailnet failedauth key 已过期或用完，或策略未定义标签用有效的 auth key 运行 tailspace install
Tailscale failed 5 times in a rowTailscale 连续 5 次崩溃、无响应或网络正常时持续离线先看 tailspace logs，再运行 tailspace start
no reason was saved停下时磁盘已满，没能写下原因腾出空间，再运行 tailspace start

因 this server must log in again 或连续失败 5 次而停止时，放弃记录只持续到下次重启服务器。若远程服务器 180 天密钥过期，在管理后台 Machines 页面点 Temporarily extend key 并在 30 分钟内关闭密钥过期，然后重启服务器即可经 cron 或下次登录重新上线。

FAQ

常见问题

远程 Tailspace 服务器的 180 天密钥过期了怎么恢复？

在 Tailscale 管理后台的 Machines 页面选择 Temporarily extend key，并在 30 分钟内关闭密钥过期。之后重启服务器或等待下次重启服务器，Tailspace 会清除上次启动的登录放弃记录，通过 cron 或下次登录重新上线。

为什么安装提示文件锁不可用或路径太长？

部分网络文件系统不支持 flock 独占锁，或家目录路径过深超过了 Unix socket 长度上限。用 TAILSPACE_PREFIX=/tmp/$USER/ts 或 /scratch/$USER/tailspace 装到本地短路径即可。

为什么 Tailspace 在连续失败 5 次后停了下来？

当 tailscaled 连续 5 次崩溃、无响应或在网络正常时持续离线，Tailspace 会停止重试以免空耗资源。查看 tailspace logs 排除原因后，运行 tailspace start 即可恢复。
