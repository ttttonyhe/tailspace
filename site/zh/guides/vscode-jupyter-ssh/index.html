Tailspace / VS Code 与 Jupyter

免 root 使用 VS Code Remote-SSH、Cursor 与 Jupyter

用 Tailspace 把共享 Linux 服务器、超算节点或 Kubernetes Pod 加入 tailnet 后，笔记本无需校园 VPN、跳板机、VS Code Tunnel 或 kubectl port-forward 就能直连 SSH、编辑器和本地 Web 服务。

SSH 端口

22 端口 Tailscale SSH 与 2222 端口 OpenSSH

Tailspace 在 22 端口开启 Tailscale SSH。如果服务器同时运行了 OpenSSH 且你没有程序占用 127.0.0.1:2222，Tailspace 会把 OpenSSH 转发到 2222 端口：

  • 22 端口（Tailscale SSH）用 Tailscale 身份认证，不需要 SSH 密钥，且 Tailscale 知道具体是哪台设备连了进来。把策略 ssh 规则里的 "check" 改成 "accept" 可跳过每 12 小时的浏览器复验。
  • 2222 端口（OpenSSH）继续沿用现有 SSH 密钥、agent forwarding 和 ~/.ssh/config。不过 OpenSSH 看到的连接都来自 127.0.0.1，authorized_keys 里的 from= 限制无法区分设备。
编辑器

VS Code Remote-SSH 与 Cursor 配置

在笔记本的 ~/.ssh/config 里添加服务器，走 Tailscale SSH 填 22 端口，走 OpenSSH 填 2222 端口：

Host lab-07
  HostName lab-07
  User you
  Port 22

在 VS Code 或 Cursor 的 Remote-SSH 里连接 lab-07 即可。想关闭 Tailscale SSH 并把 22 端口交回 OpenSSH，在服务器上运行 tailspace set --no-ssh。

本地服务

Jupyter、TensorBoard 与任意本地端口

在 userspace 模式下，除 22、2222 以及 tailscale serve 占用的端口外，其余端口全部直通服务器 127.0.0.1。启动 8888 端口的 Jupyter 或 6006 端口的 TensorBoard，本机浏览器直接打开，不需要 ssh -L 转发：

jupyter lab --no-browser --port=8888
# 在 tailnet 内任意设备打开 http://lab-07:8888

重启 Tailscale 会断开经 Tailscale 的连接，所以 Tailspace 在检测到活动 SSH 会话或 127.0.0.1、::1 上的转发连接时，会把每日更新和切回直连最多推迟 3 天。长时间训练任务仍建议放在 tmux 或 screen 里。

服务器出站

用 tailscale nc 从服务器连接其他设备

没有 root 就没有内核 tailscale0 网卡，服务器上的程序要通过 tailscale nc 访问你的其他设备。在服务器的 ~/.ssh/config 里添加一次：

Host lab-01
  User you
  Port 2222
  ProxyCommand tailscale nc %h %p

之后 ssh lab-01、scp、rsync 和 git 都能按名字连到其他 Tailspace 服务器。带 tag:server 标签的服务器互访需取消 examples/policy.hujson 中允许 tag:server 访问 tag:server 一行的注释。Tailspace 不开启无密码的 SOCKS5 和 HTTP 代理，以免同机其他用户接入你的 tailnet。

常见问题

常见问题

为什么 Tailscale SSH 每 12 小时要我在浏览器重新登录一次？

Tailscale 的默认 SSH 策略采用 check 模式，每 12 小时要求复验一次。把策略 ssh 规则里的 "check" 改成 "accept" 即可，就像 examples/policy.hujson 对 tag:server 做的那样。

在无 root 的 Tailspace 服务器上能用 curl 或 ping 访问其他 tailnet 设备吗？

没有内核 TUN 网卡，普通 ping 和不支持 tailscale nc 的程序访问不到 tailnet 地址；但 tailscale ping HOST 可用，ssh、scp、rsync 和 git 可以通过 ProxyCommand tailscale nc %h %p 正常连接。

每日更新 Tailscale 会断开我正在用的 VS Code Remote-SSH 会话吗？

不会。Tailspace 会检查活动 SSH 会话、转发到 127.0.0.1 或 ::1 的连接以及 LocalAPI 客户端，有会话时最多把更新推迟 3 天。
