非 Root 身份运行 Tailscale

在远程 Linux 服务器上常规安装 Tailscale 需要 root（管理员）权限、/dev/net/tun 和 systemd。Tailspace 会在你的家目录里以 userspace 模式免 root 运行并监管 tailscaled，让你从 tailnet 里的任何设备通过 SSH 访问超算节点、Slurm 集群或 Kubernetes Pod。

安装

在服务器上运行一行命令

打开它打印出的登录链接，完成后就能在你的任何设备上运行给出的 SSH 命令连上服务器。

$curl -fsSL https://raw.githubusercontent.com/ttttonyhe/tailspace/main/tailspace | bash

使用 auth key、HTTP 代理或自定义安装路径

用权限 0600 文件中的 auth key 无交互安装：

curl -fsSL https://raw.githubusercontent.com/ttttonyhe/tailspace/main/tailspace | TS_AUTHKEY=file:/path/to/key bash -s -- install --hostname lab-07

服务器需要 HTTP 代理上网：

export https_proxy=http://127.0.0.1:7890
curl -fsSL https://raw.githubusercontent.com/ttttonyhe/tailspace/main/tailspace | bash

家目录挂载了 noexec 或不支持文件锁：

curl -fsSL https://raw.githubusercontent.com/ttttonyhe/tailspace/main/tailspace | TAILSPACE_PREFIX=/scratch/$USER/tailspace bash

共享集群提醒。 安装前先确认集群规定，Tailspace 会维持后台进程并绕过集群两步验证。长期使用请在管理后台关闭 180 天密钥过期。

功能

让无 root 的 Tailscale 持续在线

  • SSH 与本地端口22 端口 Tailscale SSH、2222 端口 OpenSSH，直通 Jupyter 等本地端口。
  • 崩溃与服务器重启崩溃或无响应时重启 Tailscale，服务器重启后由 cron 或 0.9 毫秒 shell 检查恢复。
  • HTTP 代理切换直连路径与已保存的 HTTP 代理哪条失效就切到另一条。
  • 安全的每日更新每天检查更新，有活动会话时最多等待 3 天，新版本异常则回滚。
  • 共享主机隔离~/.tailspace 权限 700，NFS 按 state/HOSTNAME/ 隔离，关闭本地代理。
用法

常用命令

tailspace status      # 在做什么，为什么
tailspace stop        # 停止，服务器重启后也保持停止
tailspace start       # 重新启动
tailspace self-update # 更新 Tailspace 自身
tailspace uninstall   # 让服务器登出，并删除一切

支持 Linux 3.2 及以上内核与 CentOS 7，只需 bash 4.2+ 和普通用户账号。

FAQ

常见问题

没有 root 或 sudo 权限也能安装运行 Tailscale 吗？

可以。Tailspace 从官方源下载静态二进制文件到 ~/.tailspace/bin，并以 tailscaled --tun=userspace-networking 运行，不打开 /dev/net/tun，也不需要 sudo、CAP_NET_ADMIN 或 systemd。

没有 systemd，Tailscale 崩溃或服务器重启后能恢复吗？

可以。用户态监管进程在崩溃 5 秒后重启 Tailscale，并每 20 秒检查一次状态，连续 3 次无响应就重启 Tailscale。服务器重启后，有 cron 的机器由用户 crontab 立即启动，其余机器在你下次登录时由 0.9 毫秒的 shell 检查拉起。

免 root 的 Tailscale 支持 VS Code Remote-SSH、Cursor 和 Jupyter 吗？

支持。Tailspace 在 22 端口开启 Tailscale SSH，并在服务器运行 OpenSSH 时把它转发到 2222 端口，VS Code Remote-SSH、Cursor、scp 和 rsync 可以直接连上服务器的 tailnet 名字。8888 端口的 Jupyter 或 6006 端口的 TensorBoard 访问 http://主机名:8888 就能打开。

服务器在 HTTP 代理或防火墙后面怎么办？

首次安装前执行 export https_proxy=http://HOST:PORT。Tailspace 会保存这个代理，在直连路径和代理路径哪条失效时切到另一条，直连稳定后再切回。详见 HTTP 代理切换指南。

Tailspace 的 CPU 和内存开销有多大？

在有 124 个可用核心和 1,435 个可见进程、运行 Tailscale 1.104.7 的 Kubernetes Pod 上测得，每个新 shell 增加 0.9 毫秒，空闲时占一个 CPU 核心的 0.14% 和 30 MB 内存，userspace 本机回环吞吐约 10 Gbit/s。
