Tailspace / Comparison

Tailspace vs manual tailscaled and systemd --user

Most tutorials for running Tailscale without root tell you to untar the static binaries and run nohup tailscaled --tun=userspace-networking &, or to drop a unit file into ~/.config/systemd/user/. That gets you online for an afternoon. Keeping a rootless server reachable for months takes a real supervisor.

Failure modes

Where manual scripts break in practice

  • systemd --user limitsDocker and Kubernetes containers fail with System has not been booted with systemd, and on shared Linux hosts logout kills user services unless root runs loginctl enable-linger.
  • Silent network hangsChecking only whether a PID exists misses hung LocalAPI sockets and stale control connections. Tailspace polls tailscale status --json every 20 seconds and probes tailscale debug ts2021 when offline.
  • Update disconnectsIn userspace mode every connection lives inside tailscaled. Tailspace holds daily updates up to 3 days while sessions are open and rolls back failed versions after a 2-minute check and 30-second soak.
  • Unauthenticated SOCKS5Adding --socks5-server=localhost:1055 on a shared host lets every other local user reach your private tailnet. Tailspace keeps those proxies off and uses ProxyCommand tailscale nc %h %p.
  • Unbounded Go threadsOn a 124-core pod, default tailscaled starts 57 threads and scans ports every second. Tailspace sets GOMAXPROCS=8 and TS_PORTLIST=false.
FAQ

Frequently asked questions

Why not just run nohup tailscaled --tun=userspace-networking in the background?

A raw nohup daemon never restarts after a crash or reboot, never switches proxies when a VPN drops, never updates itself, and collides with other hosts when your home directory is shared over NFS.

Why not use a systemd --user unit for rootless Tailscale?

Containers and CentOS 7 hosts usually lack usable user systemd buses, and on newer Linux hosts user services stop at logout without root-enabled lingering. Tailspace works anywhere bash 4.2 runs.

Can I switch from a manual userspace setup to Tailspace?

Yes. Stop your manual tailscaled process and run Tailspace's one-line installer. Tailspace installs into ~/.tailspace and puts a configured tailscale command in ~/.local/bin.
